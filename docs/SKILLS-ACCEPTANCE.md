## Семь сценариев и дополнительные проверки

Новый [SkillsAcceptanceTest](../shared/src/jvmTest/kotlin/io/aequicor/magicpaper/data/skills/SkillsAcceptanceTest.kt)

повторное открытие → проверка точных инструкций/наблюдений/кандидата → откат → удаление
опыта → повторное открытие. Независимый импортированный baseline после удаления
сохраняется. Сценарий повторяется 5 раз для каждого из трёх поддерживаемых типов задач.
