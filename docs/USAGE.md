# Расходы и контекст

Монетка перед общими настройками открывает статистику всего приложения или текущего чата за всё время либо за сегодня (по местному времени). Расход плана включает его этапы. Для каждого провайдера и модели можно раскрыть все показатели. Доступны обращения к моделям, поиск, запросы содержимого, запрошенные страницы и токены. История до внедрения функции не пересчитывается.

Вход без кеша, чтение и запись кеша — непересекающиеся входные категории. Reasoning и кешированный вывод, если источник их сообщает, входят в выходные токены. Запись кеша не является кешированным ответом. Недоступные показатели остаются неизвестными; частично известные суммы подписаны. Стоимость провайдера и расчёт по тарифам каталога показаны отдельно. Нулевые тарифы-заглушки мостов не становятся бесплатными запросами; подписка ChatGPT не оценивается по тарифам API.

Круг в поле кодинга и планирования показывает контекст последнего активного запроса выбранного чата. `≈` означает оценку движка, `—` — ожидание сведений. Черновик и контексты параллельных исполнителей не прибавляются. Фоновые проверки и анализ закреплённых запросов учитываются в расходах, но не подменяют контекст оркестратора. Смена модели и сжатие сбрасывают известное значение до нового события движка.

Сжатие сохраняется в истории как типизированное системное событие. Одна карточка обновляется от начала до успеха, ошибки или отмены; при прерывании сохранённая карточка перестаёт показывать процесс как работающий. Скрытие служебных шагов её не скрывает. Начальный отчёт о контексте остаётся раскрываемым.

## Хранение и атрибуция

`UsageLedger` — один сохраняемый журнал на приложение (`usage:archive:v1`). Каждая операция имеет идентификатор, источник, модель, чат и при наличии родительский чат/план. `UsageOwner` переносится через фоновые корутины и потоки движков. Адаптеры сохраняют текстовый интерфейс ответа и дополнительно сообщают метрики через `UsageCall`.

Codex сообщает накопительные счётчики: журнал атомарно сохраняет прирост и курсор, исключая повторные уведомления после продолжения. При первом подключении к старой сессии учитывается только последний наблюдённый запрос. Для стороннего провайдера источником расходов служит мост; соответствующее событие Codex не добавляет вторую запись. pi передаёт usage ответа/сжатия и состояние через `getContextUsage()` расширения. В режиме JSON pi перенаправляет обычный stdout расширений в stderr, поэтому расширение записывает только метрики непосредственно в дескриптор JSON-потока.

Известные сведения сохраняются и при ошибках/отмене. Удаление чата не удаляет его расходы. Экспорт/импорт профиля включает журнал; старые файлы без него допустимы. Полный сброс очищает его. При повреждении файла исходный архив не перезаписывается измерениями текущего запуска, а меню показывает ошибку чтения.

Область покрытия — операции, наблюдаемые через интеграции MagicPaper и события движков. Недоступные источнику значения и стоимость не восстанавливаются из длины текста.

## Проверки

- `UsageParsingTest`, `UsageLedgerTest`, `SearchUsageTest`: транспорты, кеш, цены, частичные данные, повторы, параллельные области, ошибки/отмена, хранение и совместимость экспорта.
- `UsageEventsTest`, `CodexUsageEventsTest`, `MeteredRuntimeUsageTest`: lifecycle сжатия, видимость, продолжение и отсутствие двойного учёта моста.
- `PlanningRuntimeIntegrationTest` с флагами `magicpaper.pi.it=true` и `magicpaper.codex.it=true`: настоящие движки и локальный модельный сервер; число реальных запросов равно числу учтённых, кеш и контекст доходят до нужного плана.
- `provider-bridge.test.mjs`, `codex-provider-integration.mjs`, `other-providers-integration.mjs`, `pi-subscription-integration.mjs`: локальные серверы, все транспорты, инструменты, возобновление сессии, обновление тестового токена, usage сжатия и обрезанного ответа.
- `UsageUiTest`, `PaperSemanticsTest`, `CodingComposerRenderTest`: узкий/широкий интерфейс, фильтры, раскрытие, черновик и клавиатура.

Платные запросы не используются. Нативное поведение Windows требует отдельного ручного прогона; JVM-снимки на macOS его не заменяют.

Контракты источников: [Codex App Server](https://learn.chatgpt.com/docs/app-server), [OpenRouter cache usage](https://openrouter.ai/docs/guides/best-practices/prompt-caching), [каталог моделей OpenRouter](https://openrouter.ai/docs/guides/overview/models), [Google usage metadata](https://ai.google.dev/api/generate-content). Для pi сверены типы установленного API расширений и события версии 0.84.4.
