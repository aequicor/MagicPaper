# Исправления изменения плана

Проверка от `main` `ee8464c`, 9 сентября 2026 года.

## Таймаут планировщика

В сохранённом журнале запрос завершался ошибкой через 120 секунд после последней
видимой активности, до передачи `plan.propose`. События чата не отражают всю работу
нативного движка: в частности, подготовка аргументов MCP и закрытые рассуждения
могут не давать новых сообщений.

`RuntimePlanningGateway` применяет таймаут только до получения `SessionStarted`.
После запуска сессии завершением и ошибками транспорта управляет движок.
Отмена пользователем по-прежнему прерывает именно эту сессию; ошибка или неполный
ответ не становятся предложением плана.

## Остановка и выборочная пауза

`StageAttempt.interrupted` отделяет сохранённую фазу восстановления от фактического
выполнения. После прерывания карточки команд закрываются как отменённые, текущий ход
сохраняется в истории, а рабочая сессия перестаёт отображаться работающей.
Идентификаторы попытки, движка, сообщений и вызовов сохраняются. При продолжении
признак прерывания снимается после сверки состояния. Прерывание проверки не запускает
заново уже выполненные изменения исполнителя.

Информация о незавершённой внешней команде остаётся в контрольной точке: продолжение
не повторяет неоднозначное действие автоматически. Независимые этапы продолжаются.

Если доработка плана завершается ошибкой, `OrchestrationPause.requiresUser` удерживает
затронутые этапы на паузе, даже когда оркестратор обрабатывает ошибку инструмента и
завершает свой ответ. Пауза переносится на следующее предложение и снимается его
подтверждением либо явным продолжением пользователем. Автоматические сообщения
не получают права возобновить работу. `context.get` возвращает `pausedStageIds`.

Оба новых поля имеют значения по умолчанию для старых сохранений.

## Регрессионные сценарии

- `PlanningGatewayTest`: 125 секунд без видимых событий после запуска; ошибки движка,
  таймаут запуска и отмена конкретной сессии.
- `PlanningExecutionServiceTest`: выборочная пауза, сохранение частичного вывода,
  отменённые карточки, возобновление той же попытки, неизвестный результат внешней
  команды и прерывание во время проверки.
- `OrchestrationToolsTest`: вложенная доработка дольше 120 секунд, сохранение паузы
  после ошибки, запрет автоматического продолжения, явное продолжение и перенос
  удерживаемых этапов на новое предложение.
- `StageChatStateTest`: сохранённое прерывание имеет приоритет над устаревшим живым
  снимком; боковая панель и ответ перестают отображать выполнение.
- `AgentToolEngineIntegrationTest`: настоящие pi и Codex, локальная тестовая модель
  с шестисекундным молчанием при таймауте чата пять секунд, передача предложения,
  получение результата и отказ в запрещённом инструменте. Платных запросов нет.

Для запуска регрессий и настоящих движков:

```sh
./gradlew :shared:jvmTest --tests '*PlanningGatewayTest' \
  --tests '*PlanningExecutionServiceTest' --tests '*OrchestrationToolsTest' \
  --tests '*StageChatStateTest' --tests '*AgentToolEngineIntegrationTest' \
  --tests '*PlanningRuntimeIntegrationTest' \
  -Pmagicpaper.pi.it=true -Pmagicpaper.codex.it=true --offline
```

## Итоговая проверка

В контрольном worktree с копиями семи незакоммиченных правок интерфейса выполнены
`:shared:jvmTest`, `:designSystem:jvmTest`, `:desktopApp:compileKotlin`,
`:shared:compileKotlinJs` и `:shared:compileKotlinWasmJs`.

- Shared: **990 тестов, 12 прежних ошибок, 2 пропуска**. Список упавших тестов
  совпадает с предыдущей проверкой, описанной в
  [AGENT-TOOLS-VERIFICATION.md](AGENT-TOOLS-VERIFICATION.md#полный-набор-и-прежние-ошибки).
- Дизайн-система: **11 тестов, 0 ошибок**.
- Все три целевые платформы скомпилированы.
- Node: **14 тестов, 0 ошибок**.
- Итоговый целевой JVM-набор с настоящими pi и Codex: **205 тестов, 0 ошибок,
  0 пропусков**.

Исходные пользовательские правки проверяются отдельно по staged/unstaged патчам,
списку untracked файлов и контрольным суммам. Они не включаются в коммиты исправления.
Сохранения и активные сессии запущенного приложения не изменяются.
