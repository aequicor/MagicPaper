## Переиспользование и ограничения

- Сохранить SkillRepository/SkillCatalog/SkillLibrary как точки расширения,
  SkillStore.skills как источник состояния UI, SkillSelector.select как
  детерминированную основу отбора; контракт relevantFor привести к единому смыслу.
- Переиспользовать installFromCatalog/installDraft и Outcome. Сейчас commit
  проверяет лишь непустые имя/инструкцию и конфликт имени между источниками.
  При том же источнике заменяет запись с сохранением id/createdAt, но прежнего
  содержимого не хранит; enabled сбрасывается на значение входящей записи.
  Комментарий про «историю» не означает наличие истории ревизий.
- Переиспользовать SkillEducator.propose, LlmGateway.complete и редактор
  черновика. Нет проверки успешности диалога и устойчивого хранения кандидата;
  ошибка модели и пустой ответ приводят к эвристике. runCatching перехватывает
  также отмену; для будущей фоновой работы нужна корректная отмена.
- Хранилище навыков делает read-modify-write без транзакции всего обновления;
  параллельные записи могут потеряться. Повреждённый JSON считается пустым
  списком, следующая запись может затереть повреждённое содержимое.
- Нет бюджетов размера инструкции/контекста, отчёта применения и независимой
  проверки кандидата. SYSTEM-инъекция не создаёт границу доверия для внешнего текста.
- MagicAgent передаёт историю в пределах contextMessages, текущие вложения,
  подобранные навыки и при необходимости документы/поисковые результаты.
  SkillEducator передаёт только m.text, но чувствительные сведения могут уже
  находиться в тексте. Предпросмотра передаваемого контекста нет.
- В проверенной DI библиотека навыков подключена к MagicAgent; общей передачи
  этих навыков в Pi/Codex coding не обнаружено. Реальное поведение загрузки
  навыков самим app-server в данном обследовании не проверялось.
- Pi устанавливает Node с nodejs.org и пакет через npm --prefix --ignore-scripts;
  есть загрузка Git for Windows с GitHub. downloadNode следует редиректам;
  проверки контрольной суммы в прочитанной функции нет. cwd и отдельная папка
  зависимостей сами по себе не доказывают OS sandbox для Pi. Защиту Codex
  нельзя автоматически приписывать Pi.
- Удаление навыка не удаляет исходный диалог, экспортированные профили или
  уже отправленный провайдеру контекст. Гарантия удаления данных при desktop
  деинсталляции из README/комментариев отдельно не проверена.
