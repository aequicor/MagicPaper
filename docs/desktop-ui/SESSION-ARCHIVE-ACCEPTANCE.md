# Архив и поиск сессий

Кодинг-сессия архивируется после двух часов непрерывной готовности. Непрочитанные,
непроверенные, выполняющиеся и ожидающие действия задачи остаются в списке.
Обычный чат архивируется после двух суток без сообщений, если нет принятого
незавершённого запроса. Проверка выполняется при изменении состояния и раз в минуту.
Срок готовности сохраняется между запусками; старые кодинг-записи без него получают
первый срок при наблюдении. Разархивирование начинает новый срок и не запускает работу.

Вход: боковая панель → «Архив». Для восстановления нажать «Разархивировать» у записи.
Поиск в обычном списке охватывает названия, проекты и текст переписки, включая архив
и дочерние сессии. В архиве поле ограничивает поиск архивными записями.
Нажатие на найденную сессию открывает её, сохраняя признак архива.

Превью: группа `Session browser`, функции `SessionArchivePreview` и
`SessionSearchEmptyPreview` в [SessionBrowser.kt](../../app/src/commonMain/kotlin/io/aequicor/magicpaper/ui/screens/SessionBrowser.kt).
Реальные компоненты проверяются `SessionBrowserRenderTest` через ImageComposeScene
на macOS: 320×820, текст 100%; 240×820, текст 150%, плотность 1.

Semantics-проверка выполняет ввод запроса, выбор записи, очистку поиска, переход
в архив и восстановление. Сервисные тесты отдельно проверяют сохранение после
перезапуска, границы сроков, сброс готовности, ошибки записи, гонку с удалением
и отсутствие повторного запуска у восстановленных дочерних сессий.

Используются цвета Paper: текст `#35242D` на поверхности `#FFFDFA` — 14,35:1,
на выделении `#DDD2EB` — 10,05:1; действие `#62558D` на `#F3EBDD` — 5,54:1.
Метаданные и фрагмент переписки расположены на обычной поверхности.

Отдельные нативные прогоны Windows, VoiceOver/NVDA, ручные прогоны Android/browser
и измерение FPS на большом архиве не выполнялись. Compose-рендер и компиляция
не заменяют эти проверки.
