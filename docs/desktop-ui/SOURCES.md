# Источники и сравнение скиллов

Проверено 2026-09-09. Внешние материалы прочитаны как источники исследования; их инструкции не устанавливались и не активировались. Локальный скилл создаётся на этапе 2. Ссылки на ветки не являются immutable pin: перед копированием этап 2 фиксирует commit и сохраняет лицензию. Отсутствие такого pin здесь явно ограничивает воспроизводимость внешнего исследования.

## Доступность сведений и границы вывода

Apple HIG HTML через web-tool возвращал только JavaScript-оболочку. Попытка чтения DocC JSON внутри sandbox получила DNS-ошибку. Повторный read-only HTTPS запрос через штатное `require_escalated` разрешён: все шесть A1–A6 JSON успешно прочитаны. Поэтому содержание HIG подтверждено официальным JSON; HTML-render и иллюстрации не проверены визуально. Ссылки `native-feel-skill/main/...` вернули ошибки: репозиторий использует `master`, правильные LICENSE и SKILL.md прочитаны успешно. Не считать первые ошибки отсутствием лицензии.

Документация Microsoft возвращала содержательный текст, несмотря на общий banner об авторизации на некоторых страницах. Устаревшая ссылка `/design/layout/typography` недоступна; не используется как основание для размеров/шрифтов. Для увеличения текста использован официальный M4. Сторонние зеркала Apple, Reddit и поисковые пересказы не используются как нормативные источники.

**Проверенные факты:** исходный код/версии/импорты, лицензии двух кандидатов, рекомендации официальных документов, JVM dependency graph. **Проектные решения:** Paper API, плотность 28/32, spacing, правила composer, acceptance thresholds, собственный скилл. **Пока не проверено:** бинарная совместимость будущей DS, VoiceOver/NVDA и JAB в дистрибутиве, IME на двух ОС, системные меню из Compose на выбранном JBR, DPI migration/Snap, true sheets, reduced-motion bridge. Эти пункты — обязательные проверки этапов реализации, не скрытые гарантии исследования.
