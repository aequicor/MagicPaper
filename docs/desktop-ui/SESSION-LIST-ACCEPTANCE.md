# Единый список сессий

2026-09-16. Область: боковая панель приложения, `UnifiedSidebar` →
`UnifiedSessionFeed`. Исходные данные и команды принадлежат приложению;
геометрия строки и закрепление дерева — `PaperSessionRow` и `PaperStickyTree`.

## Источник и решения

Найденный по запросу репозиторий:
[willyp713/awesome-ui-guides](https://github.com/willyp713/awesome-ui-guides).
Это каталог руководств по доступности, навигации, кнопкам и другим элементам UI.
Из него не копировались исходники и не устанавливались зависимости.
Принятые для MagicPaper решения: общая геометрия строк, явное раскрытие,
постоянное место индикатора, доступное без наведения меню, ограниченные отступы
и сохранение контекста прокрутки. Три уровня закрепления — требование задачи.

Чат разделяет соседние по времени сессии одного проекта на отдельные группы.
Повторное название проекта после чата обозначает продолжение хронологии.
Идентификаторы, сохранённая история и команды запуска не изменены.
Вложенные сессии сохраняют родительские связи; архивный промежуточный узел
скрывается, его потомки появляются один раз под ближайшим видимым предком.

`PaperStickyTree` использует ленивый список и до трёх закреплённых предков:
проект → задача → родительская сессия. Одиночный `LazyColumn.stickyHeader`
не удерживает несколько предков одновременно, поэтому Paper рассчитывает
положение по видимым строкам и измеренным высотам заголовков. На границе ветви
уходят только соответствующие заголовки; перед чатом уходит весь стек.
Прокрутка не создаёт вторые доступные кнопки: исходная закреплённая строка
заменяется размерным заполнителем. Раскрытие удерживает нажатую строку на месте.

## Приёмка

Маршрут: открыть боковую панель, раскрыть проект, задачу и родительскую сессию.
Прокрутить потомков, свернуть закреплённого родителя, затем прокрутить к чату
между двумя группами одного проекта. Название открывает сессию; стрелка
раскрывает без смены выбора. Left/Right управляют раскрытием, Enter открывает
сессию. Меню и создание сессии видимы и доступны с клавиатуры.

Именованные Compose Preview: `UnifiedSessionFeedPreview`, группа `Session list`,
случаи `Chronology and tree` и `Narrow large text`.
Рендеры получены реальными composable через `ImageComposeScene` на macOS:

Рендеры осмотрены. Текст и индикаторы имеют общие направляющие; отступ дерева
ограничен тремя шагами. В узком режиме полное название остаётся в семантике,
переполнение затухает и прокручивается при наведении.
Контраст используемых непрозрачных пар: основной текст/бумага 14,35:1,
основной текст/выбор 10,05:1, вторичный текст/бумага 6,30:1;
контур готовности/бумага 8,17:1, контур ожидания/бумага 5,61:1.

Открытие сессии и раскрытие требуют по одному нажатию. Архив и удаление
доступны через единое меню в два нажатия; раньше архив был отдельной кнопкой
при наведении. Выбрано постоянное компактное меню для одинакового доступа
мышью, клавиатурой и касанием. Подтверждения удаления остаются у сервиса.

PASS: тесты геометрии границ дерева, проекции архивных родителей, хронологии,
фильтрации, сохранения настроек списка, выбора и раскрытия через semantics,
клавиатурных Left/Right/Enter; компиляция desktop, Android, JS и Wasm.
PASS: Paper boundary, surface map, module architecture и diff checks.

NOT_RUN: native Windows, Android/browser runtime, VoiceOver/NVDA,
интерактивный IDE Preview и замеры FPS в установленном приложении. Compose
рендеры и компиляция не заменяют эти проверки. Для native-приёмки повторить
прокрутку и сворачивание на целевой ОС; проверить колесо/трекпад над закрепами,
Tab и меню, масштаб 100–200%, длинное дерево во время обновления статусов.
