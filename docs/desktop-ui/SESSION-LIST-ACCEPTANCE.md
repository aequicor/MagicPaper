# Единый список сессий

Актуальная проверка закрепов: 2026-09-18. Область: боковая панель приложения,
`UnifiedSidebar` → `UnifiedSessionFeed`. Данные и команды принадлежат приложению;
геометрия строк и закрепление — `PaperSessionRow` и `PaperStickyTree`.

## Поведение

Закрепы сохраняют порядок исходного списка: проект, затем его сессии. Выбранная
сессия сохраняет место среди остальных строк, а не переносится выше проекта.
Всего видно до четырёх закрепов: место проекта и выбора сохраняется, оставшиеся
места занимают последние подходящие статусные строки. Выбранная строка остаётся
при переходе между группами, пока она присутствует в отфильтрованном,
развёрнутом списке. Сворачивание проекта или удаление строки из списка освобождает
её закреп. «Готова к работе» сама по себе не закрепляется.

Чат может разделять сессии одного проекта на отдельные хронологические группы.
Все сессии внутри проекта имеют один визуальный отступ. Выбор открывает сессию;
кнопка раскрытия проекта меняет только раскрытие. Команды архивирования,
удаления, идентификаторы и сохранённая история не изменены.

`PaperStickyTree` использует ленивый список и измеренные высоты строк:
`LazyColumn.stickyHeader` не удерживает несколько предков одновременно.
Геометрия сопоставляется по стабильным ключам: старые индексы layout после
фильтрации, перестановки или сворачивания не означают другие объекты нового списка.
Полная цепочка предков сохраняется при ограничении числа закрепов, поэтому
следующий заголовок закрепляется на границе стека до исчезновения своей строки.
Граница принадлежности задаётся `ancestors`; предыдущая соседняя строка не
считается предком автоматически. На границе ветви уходят только её заголовки.
Естественная копия закрепа остаётся измеренной под оверлеем, её семантика скрыта.

## Приёмка

Маршрут: открыть «Сессии», раскрыть проект с выбранной сессией и несколькими
работающими/непрочитанными сессиями. Прокрутить вниз, сменить выбор, свернуть и
раскрыть закреплённый проект, затем вернуться в начало списка. Проверить порядок
«проект → сессии», отсутствие скрытых закрепов и повторных доступных кнопок.
Колесо над закреплённой строкой продолжает прокрутку; наведение открывает действия.
