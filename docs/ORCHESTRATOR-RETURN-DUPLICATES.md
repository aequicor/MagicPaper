# Повтор ответа при возврате работы исполнителю

9 сентября 2026 года. Дефект воспроизведён на `ea3eb53` в момент записи ответа:
регрессионный тест получил два экземпляра текста вместо одного.

## Причина

После завершения модели ответ оркестратора записывается в историю, а его живое
состояние очищается позднее, после применения решения и сохранения передачи
управления. Экран может получить сохранённое сообщение и прежний живой снимок
одновременно. Карточки инструментов уже сопоставлялись по идентификаторам вызовов,
но текст в общем потоке оркестратора терял связь с сообщением истории.

## Исправление

- Каждое обращение к оркестратору получает идентификатор будущего ответа до начала
  вывода. `CodingStep.sourceTimelineId` сохраняет эту принадлежность при объединении
  нескольких обращений и пользовательского запроса в один живой поток.
- Сохранённое сообщение получает идентификатор уже отображаемого текста. Ключ
  элемента списка сохраняется при записи истории и при завершении соседнего этапа.
- Проекция чата исключает живую копию уже сохранённого ответа по его идентификатору.
  Сравнение текста не используется: одинаковые ответы разных этапов остаются разными.
- Ошибка до сохранения завершает тот же источник вывода. Ошибка после сохранения
  добавляет диагностику без повторного копирования всей ленты инструментов.
- Новое поле необязательно при чтении старых сохранений. Существующая история
  не переписывается и не запускает действия заново.

## Проверки

`PlanningChatServiceTest` перехватывает запись истории до очистки живого состояния,
проверяет параллельные обращения и ошибку после публикации ответа.
`CodingChatRowsTest` проверяет смешанный поток, одинаковые тексты разных этапов,
сохранение ключей и завершение частичного ответа ошибкой.
`CodingChatCommitTest` проверяет настоящий экран покадрово, отсутствие дубля,
сохранение позиции и прежние сценарии раскрытых инструментов.

```sh
./gradlew :shared:jvmTest --tests '*PlanningChatServiceTest' \
  --tests '*PlanningReplyPreviewTest' --tests '*CodingChatRowsTest' \
  --tests '*CodingChatCommitTest' --tests '*OrchestrationToolsTest' --offline
```

Снимок проверяемого перехода создаётся в
`shared/build/reports/chat-scroll-stability/orchestrator-return-saved.png`.
